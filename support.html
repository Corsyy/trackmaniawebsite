Support Trackmania Events

Trackmania Events is built and maintained as a free community resource for schedules, live events, records, Track of the Day data, Weekly Shorts stats, and community updates.

Optional support helps cover hosting, tools, data updates, and development time. There is zero pressure — using the site, sharing it, and submitting events already helps a lot.

What support helps with

Trackmania Events takes time to build, test, maintain, and keep updated. Support helps make future improvements easier to keep working on.

  • Hosting, domain, and site-related costs.
  • Keeping event pages, stats, and records updated.
  • Adding new features for players, organizers, and viewers.
  • Improving mobile layouts, performance, and reliability.

No pressure at all

The site is meant to stay useful and accessible for the community. Supporting is simply a way to help out if you enjoy the project and want to contribute.

  • Sharing the site helps.
  • Submitting events helps.
  • Reporting bugs helps.
  • Optional Ko-fi support helps too.

Supporter perks

The useful parts of Trackmania Events are not locked behind payment. Any perks are meant to be small, cosmetic, and community-focused.

  • Supporter name listed on a future supporters section.
  • Possible supporter badge in the shoutbox.
  • Early previews or feedback on upcoming site features.
  • A simple way to help keep the project active.
Leaderboards, event browsing, Track of the Day data, Weekly Shorts stats, and core site features are intended to stay free for everyone.

Thank you for using Trackmania Events — support is appreciated, but never required.
