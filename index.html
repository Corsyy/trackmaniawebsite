About

Trackmania Events is a community-run hub built around one simple goal: make it easier to see what is happening in the Trackmania scene.

The main focus is events. Players should be able to find upcoming races, and organizers should have a straightforward place to submit what they are hosting. Stats, recent records, highlights, shoutbox updates, badges, and Prize Runs are supporting features that make the site feel active between events.

The site is still growing, so feedback from players and event hosts is always welcome.
